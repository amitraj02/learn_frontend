▲ The Full-Stack React Framework for the Web

Master Next.js App Router the Simple Way

Used by Netflix, Uber, TikTok, and GitHub. Next.js enables you to create full-stack Web applications by extending the latest React features, including Server Components, nested routing, and Server Actions.

Module 01

The 4 Rendering Strategies (CSR, SSR, SSG, ISR)

Understanding when and where your HTML is created is the foundation of Next.js:

Strategy Full Name When is HTML Created? Best Used For
CSR Client-Side Rendering In user's browser via JavaScript Private user profile, internal SaaS tools
SSR Server-Side Rendering On the server on every request Live stock quotes, dynamic order book
SSG Static Site Generation At build time (cached forever) Blogs, documentation, marketing landing pages
ISR Incremental Static Regeneration Built static, revalidated in background every N seconds E-commerce product lists, daily financial summaries
💡 ISR in 1 Line of Code:
Just add export const revalidate = 60; to any page. Next.js will serve the static cache, and regenerate fresh data in the background every 60 seconds!
Module 02

Server Components vs Client Components

In the Next.js App Router, every component is a React Server Component (RSC) by default!

The Server Component Architecture

🖥️ Server Component (Default)
Fetches DB & API securely (0 KB JS)
➔ passes data down ➔
💻 Client Component ('use client')
Handles button clicks & useState
app/stocks/page.tsx (Server Component)
// This runs ON THE SERVER. No client JS is sent!
import BuyButton from './BuyButton'; // Client component

export default async function StocksPage() {
  // Direct database query! No public API exposure!
  const stocks = await db.query('SELECT * FROM watchlist');

  return (
    <div>
      <h1>Live Stocks</h1>
      {stocks.map(s => (
        <div key={s.id}>
          <span>{s.symbol}: ₹{s.price}</span>
          <BuyButton ticker={s.symbol} />
        </div>
      ))}
    </div>
  );
}
app/stocks/BuyButton.tsx (Client Component)
'use client'; // <-- Mandatory for useState or onClick!

import { useState } from 'react';

export default function BuyButton({ ticker }: { ticker: string }) {
  const [bought, setBought] = useState(false);

  return (
    <button onClick={() => setBought(true)}>
      {bought ? '✔ Order Placed' : `Buy ${ticker}`}
    </button>
  );
}

Module 03

Server Actions ('use server') — Zero-API Mutations

Server Actions allow client components and HTML forms to invoke server-side functions directly, without writing separate API controllers!

app/actions.ts (Server Action)
'use server'; // <-- Declares all exports as Server Actions!

import { revalidatePath } from 'next/cache';

export async function placeOrder(formData: FormData) {
  const symbol = formData.get('symbol');
  const qty = Number(formData.get('qty'));

  // Run backend database mutation
  await db.orders.create({ symbol, qty });

  // Instantly purge stale cache and refresh page UI!
  revalidatePath('/dashboard');
}
app/trade/page.tsx (Form with Action)
import { placeOrder } from '../actions';

export default function TradePage() {
  return (
    <form action={placeOrder}>
      <input name="symbol" defaultValue="INFY" />
      <input name="qty" type="number" defaultValue="50" />
      <button type="submit">Execute Order</button>
    </form>
  );
}

Interview Prep

Top Next.js Interview Questions & Answers

Q1: What is the main difference between layout.tsx and template.tsx?

layout.tsx preserves state across child route transitions and does not re-render. template.tsx creates a fresh instance and re-mounts on every route change, resetting component state and re-syncing effects.

Q2: Why does Next.js 14 use Server Components by default?

Zero bundle size impact! Server components do not send their JavaScript code or heavy libraries (like Markdown parsers or DB drivers) to the client browser, resulting in blazing fast First Contentful Paint (FCP).

Q3: What does 'use server' at the top of a file mean?

It marks all exported async functions in that file as Server Actions, allowing client components or HTML forms to execute them seamlessly via POST requests with automatic CSRF protection.
