React Tutorial

React is a JavaScript library for building user interfaces. React is used to build single-page applications. React allows us to create reusable UI components.

React ES6 Pre-requisites

Before learning React, you only need to know a few modern ES6 JavaScript concepts:

1. Arrow Functions

Arrow functions allow us to write shorter function syntax:

JavaScript ES6
// Before ES6:
var hello = function() {
  return "Hello World!";
}

// With ES6 Arrow Function:
const hello = () => "Hello World!";

2. Destructuring (Super Important in React!)

Destructuring allows you to easily extract values from arrays or objects into distinct variables:

Destructuring Objects & Arrays
const stock = { symbol: "RELIANCE", price: 2950, exchange: "NSE" };

// Instead of stock.symbol, stock.price:
const { symbol, price } = stock;

// Array destructuring (This is how useState works!):
const fruits = ["Apple", "Banana"];
const [first, second] = fruits;

3. Spread Operator ...

The spread operator allows us to quickly copy all or part of an existing array or object into another array or object:

Spread Operator
const numbersOne = [1, 2, 3];
const numbersTwo = [4, 5, 6];
const combined = [...numbersOne, ...numbersTwo]; // [1, 2, 3, 4, 5, 6]

React Render HTML

React renders HTML to the web page by using a function called createRoot() and its method render().

index.js (React 18 Standard)
import React from 'react';
import ReactDOM from 'react-dom/client';

const container = document.getElementById('root');
const root = ReactDOM.createRoot(container);
root.render(<h1>Hello React 18!</h1>);
Note: In React 18, ReactDOM.render was replaced by ReactDOM.createRoot to enable concurrent rendering features!

React JSX

JSX stands for JavaScript XML. JSX allows us to write HTML in React. JSX makes it easier to write and add HTML in React.

Expressions in JSX

With JSX you can write expressions inside curly braces { }. The expression can be a React variable, or property, or any valid JavaScript expression.

🧪 Try it Yourself: JSX Expressions JSX live evaluation
Important JSX Rules:
  • Elements must be closed (e.g. <img />, <br />).
  • Use className instead of class.
  • Always return one top-level element (or use Fragment <> ... </>).
