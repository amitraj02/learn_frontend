## 🧠 The 4 Core Mental Models of React

1. **Declarative UI**: You don't micromanage DOM elements (`document.getElementById`). You declare *what* the UI should look like based on data, and React handles the updates.
2. **Components as LEGO Bricks**: Every UI piece is an independent function returning JSX.
3. **Props Flow Down (Read-Only)**: Data flows from parents to children. A child component never alters its props.
4. **State Triggers Re-Renders**: When a component's internal state changes via its setter function, React re-renders that component and reconciles changes via the Virtual DOM.
