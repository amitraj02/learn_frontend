JavaScript Variables (let, const, var)

Variables are containers for storing data values. In modern JavaScript (ES6+), we have three ways to declare a variable:

Keyword Scope Can Reassign? Hoisted? When to Use
const Block { } ❌ No Temporal Dead Zone Default choice (90% of your code!)
let Block { } ✅ Yes Temporal Dead Zone When variable will change (loops, counters)
var Function ✅ Yes Hoisted as undefined Avoid in modern JS (legacy keyword)

Data Types & Strict Equality (=== vs ==)

JavaScript has 7 primitive types (Number, String, Boolean, Null, Undefined, BigInt, Symbol) and Object reference types.

⚠️ The == vs === Difference:
== (Loose Equality) performs automatic type conversion before comparing.
=== (Strict Equality) compares value AND type without conversion. Always use ===!

Functions & Arrow Syntax

A JavaScript function is a block of code designed to perform a particular task.

Function Declaration vs Arrow Function
// 1. Traditional Function Declaration:
function calculateTurnover(shares, price) {
  return shares * price;
}

// 2. Modern ES6 Arrow Function (Concise):
const calculateTurnover = (shares, price) => shares * price;

Top JavaScript Interview Questions & Answers

Q1: What is the Event Loop and how does it handle asynchronous code?

JavaScript is single-threaded with one Call Stack. Asynchronous tasks (like Promises and timers) are handled by Web APIs. When completed, their callbacks go into the Microtask Queue (Promises) or Macrotask Queue (setTimeout). The Event Loop pushes tasks onto the Call Stack whenever it becomes empty, prioritizing microtasks first!

Q2: What is the difference between null and undefined?

undefined means a variable has been declared but has not yet been assigned a value. null is an assignment value that represents an intentional absence of any object value.
